Project detail

Fuel Efficiency Analysis

A Power BI dashboard exploring fuel use and related operational measures across ship and route dimensions.

Project overview

What this project covers

The supplied dashboard pages include views of fuel consumption by ship ID, CO₂ emissions by ship type, fuel consumption by weather condition, route-related comparisons and a trend visual. The dashboard also displays KPI cards for distance, emissions, fuel consumption and an average engine measure.
