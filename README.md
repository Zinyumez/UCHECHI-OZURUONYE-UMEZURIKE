# Uchechi Umezurike Ozuruonye — Data Analyst Portfolio

A responsive HTML/CSS portfolio showcasing four dashboard projects. The website displays dashboard screenshots only as project visuals; LinkedIn screenshots, social-media reactions, comments, and CV images are not included.

## Projects
- HR Attrition Analysis (Power BI)
- Fuel Efficiency Analysis (Power BI)
- Breast Cancer Data Analysis (Power BI)
- Employee Attrition & Workforce Performance (Excel)

## Files
- `index.html` — portfolio homepage
- `project-*.html` — individual project pages
- `style.css` — website styling
- `assets/` — dashboard screenshots used by the site

## Publish with GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
